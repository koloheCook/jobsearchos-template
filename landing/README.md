# landing/ -- inbox

Drop JD PDFs here. Chrome and local URL capture write primary Markdown artifacts to
`web-captures/`, which is intentionally separate so a browser grant cannot access
the ledger or run log. Run `jd-intake` (or wait for the scheduled run) and
each new intake unit becomes an opportunity folder with a triage assessment. The
ledger is append-only. Contents of this folder, except committed control files, are
never committed.
