# jobSearchOS rubric backtest — single role

Once you have calibrated the rubric (rubric/fit-rubric.md + rubric/deal-breakers.md),
before trusting it live, backtest it against past roles I was interested
in or applied to. One role per session to keep scoring clean; results aggregate to
rubric/backtest-log.md.

ROLE FOR THIS SESSION: <paste a Notion page URL, a JD link, or the JD text for the past role you're backtesting>

Do this, in order:
1. Read rubric/fit-rubric.md and rubric/deal-breakers.md fresh. They are the source of
   truth — score against the WRITTEN anchors, not memory or vibes.
2. Read the full JD from the link or pasted text above (for a Notion page, read the PAGE
   BODY where the JD is transcribed, not just the title).
3. Score each fit-rubric axis (Lane fit, Level, Comp, Location/remote, Mission/domain
   pull) 0-10 against the written anchors only. For each score, cite the exact anchor
   that produced it (SCRIBE / cite-the-anchor). No invented facts (NO-INVENTED-METRIC,
   ASK-DONT-GUESS): if the JD omits comp/location/etc., say "not stated," do not guess.
4. Run the deal-breaker gate against your calibrated rubric/deal-breakers.md (comp
   floor hard; undisclosed comp = UNRESOLVED-comp, which does NOT block -- it just
   flags), location, entity viability. Mark each RESOLVED-PASS / RESOLVED-FAIL /
   UNRESOLVED with the named fact.
5. Emit a verdict: PURSUE / EXPLORE / PASS.
6. THEN ask me: did I actually pursue/apply to this role, and would I still today?
   Capture my stated gut in one line.
7. Compute MATCH (rubric verdict aligns with my gut) or MISMATCH. On MISMATCH, name the
   SINGLE axis most responsible — that axis is the calibration candidate.
8. Append ONE row to rubric/backtest-log.md (create the file with the header below if it
   doesn't exist; APPEND-ONLY, never edit prior rows):
   | Date | Company / Title | Lane | Level | Comp | Loc | Mission | Gate result | Rubric verdict | My gut | MATCH? | Axis at fault |
9. Print the row back to me.

Score only this one role. Do not batch.
