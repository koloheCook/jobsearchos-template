## Hard deal-breakers (a role failing ANY of these is a PASS or a gated EXPLORE)
1. **Comp floor:** base salary >= <YOUR_COMP_FLOOR>, genuinely never-below regardless
   of mission or lane fit. CARVE-OUT: comp is almost never in the JD and the owner
   initiates by applying, so undisclosed comp does NOT block the initial application /
   resume submission -- it flags UNRESOLVED-comp and becomes must-resolve-before-offer
   (get the range on the recruiter screen; that resolving action goes in Next 3 Moves).
   Equity is not scored (rarely disclosed; cannot be valued consistently).
2. **Location / relocation:** <OWNER: your commute/remote tolerance and hard
   location exclusions. Example shape: "a non-remote role must be reachable without
   a car"; name any relocation exceptions explicitly.>
3. **Industry / values exclusion:** <OWNER: any industries or business models you
   rule out on principle, e.g. defense/weapons, gambling, adult, surveillance --
   auto-PASS.>
4. **Security clearance:** <OWNER: which U.S. security clearances you hold, or "none".> A
   role that requires, or may require, a clearance you do not hold (Confidential, Secret,
   Top Secret, TS/SCI, or any DoD/IC clearance) -- FAIL. Delete this rule if clearance
   roles are fine for you. This covers a present requirement to hold
   an active clearance AND a conditional or future requirement to obtain, hold, be eligible
   for, or be able to obtain one (for example "may be expected to obtain and hold", "must be
   able to obtain", "clearance-eligible"). A JD that states no clearance is required, or is
   silent on clearance, is RESOLVED-PASS. An export-control / U.S.-person authorization
   notice that does not name a security clearance is a separate consideration, not this gate.

## Gate procedure (imported from the source pattern, verbatim in spirit)
- Each deal-breaker per assessment gets: RESOLVED-PASS / RESOLVED-FAIL / UNRESOLVED
  plus the named fact (or the missing fact).
- UNRESOLVED on any hard deal-breaker: "Do not send tailored materials until a
  recruiter call / named source resolves: <list>." The assessment's Next 3 Moves must
  include the resolving action. (Comp exception per #1: undisclosed comp does not block
  the initial application, only later high-investment tailoring and the offer.)
- RESOLVED-FAIL: verdict is PASS unless the owner explicitly overrides in writing in the
  assessment file (the override is itself a dated decision).
