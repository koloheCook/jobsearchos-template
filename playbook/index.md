## Usage rules

1. Load this index and only the module keyed to each expected question. Do not load
   the entire `modules/` directory.
2. Map every expected meeting question to exactly one module number in the meeting
   brief's module-map table.
3. Modules are talk-track beats, not a script. The brief owns the only verbatim
   opener.
4. Every module must end with exactly one bridge question. Do not invent evidence or
   metrics. Use `[METRIC NEEDED]` when a sourced value is unavailable.
5. Headless runs never edit `playbook/`. Version bumps require owner approval,
   a changelog entry, and a regenerated `core-messaging.md`.
